Advanced CSS Properties

This document demonstrates the use of custom properties in CSS.

Custom properties, also known as CSS variables, allow you to store values that can be reused throughout your stylesheet.

In this example, we define a custom property for the background color and change it on hover.

By using the @property rule, we can create a custom property with specific syntax, inheritance, and initial values.

This allows for more control and flexibility in styling elements.

For example, we can easily change the background color across multiple elements by updating the custom property.

Custom properties can also be used in conjunction with JavaScript to create dynamic styles.
